Tipos

Quantidades são representadas na linguagem R a partir de tipos ‘primitivos’. Mais detalhes podem ser conferidos em R Manual.

Numérico

Variáveis da classe numérica podem conter valores especiais.

qtd_real <- 400
qtd_real_com_decimais <- 400.5

qtd_real_especial <- NaN
qtd_real_especial2 <- NULL
qtd_real_especial3 <- Inf

[1] Inf
0/0
[1] NaN

[1] NaN

qtd_real2 <- 400
qtd_real3 <- 15

Inteiro

Coleções

Vetores

Vetores são coleções homogenêas de dados. Caso seja possível, o R efetuará a conversão para o maior tipo presente na declaração.

exemplo_coercao_tipos <- c(10, 4.5, "teste")

exemplo_coercao_tipos2 <- c(10L, 4, 1L)
typeof(exemplo_coercao_tipos2)
[1] "double"
exemplo_coercao_tipos3 <- c(T, 4.5, c(1, 2), "teste")
typeof(exemplo_coercao_tipos3)
[1] "character"
x <- c(0, 0, 1)
y <- c(0, 1, 0)

Listas

Listas são coleções heterogêneas ‘nomeadas’. Listas são coleções ordenadas e podemos acessar seus componentes utilizando ‘$’ ou utilizando [[nome_componente]].

lista_exemplo <- list(pessoa1="Fred", pessoa2="Velma", criancas=3, idades=c(4,7,9))

lista_exemplo2 <- list(pessoa3="Fred2", pessoa4="Mary4", criancas=5, idades=c(4,7,9,11,12))

lista_exemplo$pessoa1
[1] "Fred"
lista_exemplo$idades[2]
[1] 7
lista_exemplo$pessoa3
NULL
lista_exemplo$pessoa1 == lista_exemplo[["pessoa1"]]
[1] TRUE
lista_resultante <- c(lista_exemplo, lista_exemplo2)

print(lista_resultante$pessoa1)
[1] "Fred"
print(lista_resultante$pessoa3)
[1] "Fred2"

FiltraVetor <- function(z, corte = NA) {
  if (is.na(corte)) {
    return(z[z > 90])
  }
  return(z[z > corte])
}
